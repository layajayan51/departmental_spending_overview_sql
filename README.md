# 💼 Departmental Spending Overview

## Overview
This project analyzes **spending across departments** on various projects using SQL.  
The goal is to identify departments with **significant expenses** and highlight overall spending trends.

## Tech Stack
- **SQL** (queries for aggregation and filtering)

## Features
- Department-wise spending breakdown  
- Aggregated totals and comparisons  
- Identification of high-spending departments  

## Purpose
A simple project to practice **SQL data analysis**, focusing on organizational spending behavior.
